# Retrouver les résultats

Sous `<OPENCLAW_LOCAL_ROOT>\projects\<id>` :

| Dossier | Contenu |
|---|---|
| `context/` | analyse, plan, clarifications, assignations, décisions |
| `work/` | travail intermédiaire |
| `deliverables/` | livrables et package final |
| `evidence/` | résultats, validations, reviews et rapport final |
| `diagrams/` | schémas du projet |
| `context/exchange/` | échanges versionnés entre tâches |

## Réflexe

Pour remettre un fichier à quelqu'un, privilégier `deliverables/`. `work/` n'est pas un emplacement de livraison finale.
