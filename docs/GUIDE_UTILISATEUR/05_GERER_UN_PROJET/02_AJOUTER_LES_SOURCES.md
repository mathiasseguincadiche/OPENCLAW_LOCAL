# Ajouter ou remplacer des sources

## Principe

Les sources de travail et l'intake d'origine n'ont pas le même rôle. Ne modifiez pas l'intake immuable pour refléter silencieusement une nouvelle demande.

## Avant changement

1. identifier si le nouvel élément est une nouvelle consigne, une nouvelle source ou une correction ;
2. vérifier son impact sur l'analyse et le plan ;
3. utiliser le mécanisme d'intake/projet prévu plutôt que déposer un fichier dans un workspace agent ;
4. relancer l'analyse lorsque le changement modifie le besoin.

La provenance et les hashes doivent permettre de savoir quelle version a servi au travail.
