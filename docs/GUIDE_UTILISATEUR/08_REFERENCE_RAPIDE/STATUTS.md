# Statuts — référence rapide

```text
INTAKE_READY             entrées prêtes
ANALYZED                 besoin analysé
CLARIFICATION_REQUIRED   décision humaine requise
PLANNED                  plan construit
ASSIGNED                 tâches attribuées
IN_PROGRESS              exécution/corrections
VALIDATING               contrôles techniques
REVIEW                   revue globale indépendante
PACKAGING                assemblage final
COMPLETE                 fin approuvée humainement
```

`VALIDATING` et `REVIEW` peuvent revenir à `IN_PROGRESS`. Un `STOP` peut être normal.
