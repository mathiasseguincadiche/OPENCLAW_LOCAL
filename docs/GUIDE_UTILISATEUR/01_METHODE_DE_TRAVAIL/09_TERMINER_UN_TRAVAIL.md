# Terminer un travail

## Checklist

- [ ] tous les livrables attendus existent ;
- [ ] les contraintes sont respectées ;
- [ ] les validations techniques sont `PASS` ;
- [ ] la revue indépendante est `PASS` ;
- [ ] les corrections sont intégrées ;
- [ ] les preuves sont conservées ;
- [ ] le package final est identifiable ;
- [ ] les limites ou risques résiduels sont explicités ;
- [ ] l'humain a réellement vérifié ce qu'il approuve.

Dans le Project Orchestrator, `COMPLETE` n'est pas automatique : après `PACKAGING`, l'utilisateur approuve explicitement avec `--human-approved`.
