# Définir son objectif

## But

Transformer une idée vague en résultat vérifiable.

## Mauvais objectif

> Améliore mon Kubernetes.

## Bon objectif

> Rendre le déploiement `p4-dev` fonctionnel sans modifier le code Java ; tous les pods doivent être `Ready`, le backend doit résoudre PostgreSQL et les commandes de validation doivent être fournies.

## Questions à remplir

- quel problème ou résultat vise-t-on ?
- quel périmètre est inclus ?
- qu'est-ce qui est explicitement hors périmètre ?
- quelle sortie concrète doit exister ?
- comment saurons-nous que c'est correct ?

Écrivez l'objectif avant de choisir l'agent. Si vous n'arrivez pas à le formuler, utilisez `chef-operations` pour le cadrage.
