# Formuler la mission

## Modèle recommandé

```text
OBJECTIF
...

CONTEXTE
...

ENTRÉES
...

CONTRAINTES
- ...

LIVRABLES
- ...

CRITÈRES DE RÉUSSITE
- ...

MÉTHODE
1. analyse avant modification ;
2. signale les ambiguïtés bloquantes ;
3. propose/actualise le plan ;
4. exécute ;
5. teste ;
6. fournis les preuves et les limites restantes.
```

## Pourquoi

Cette structure sépare le « quoi » du « comment » et évite qu'un agent interprète une préférence comme un critère obligatoire ou qu'il considère une sortie non testée comme terminée.
