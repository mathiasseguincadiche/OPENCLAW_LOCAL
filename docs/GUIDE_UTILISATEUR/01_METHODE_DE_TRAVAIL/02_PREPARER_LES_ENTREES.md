# Préparer les entrées

## À fournir selon le besoin

- consignes et cahier des charges ;
- fichiers ou dépôt source ;
- architecture connue ;
- état actuel et environnement ;
- logs/erreurs observés ;
- contraintes techniques et métier ;
- livrables attendus ;
- critères de validation.

## À éviter

- tokens, mots de passe et secrets non nécessaires ;
- fichiers sans rapport avec le travail ;
- modifier les consignes originales pour « aider » l'IA ;
- mélanger copie de travail et source de vérité.

## Projet orchestré

Les consignes deviennent l'`intake`; les fichiers de travail deviennent les `sources`. L'intake est protégé pour préserver la référence initiale.
