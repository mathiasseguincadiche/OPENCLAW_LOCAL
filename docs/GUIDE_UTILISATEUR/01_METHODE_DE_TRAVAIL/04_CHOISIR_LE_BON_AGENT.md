# Choisir le bon agent

| Besoin principal | Agent |
|---|---|
| cadrer / découper / coordonner | `chef-operations` |
| faits, sources, Web | `expert-recherche` |
| architecture et compromis | `architecte-solutions` |
| CI/CD, conteneurs, IaC, scripts | `ingenieur-devops` |
| sécurité et hardening | `ingenieur-securite` |
| Git, PR, release, packaging | `ingenieur-release-forges` |
| documentation et runbooks | `redacteur-technique` |
| validation/revue indépendante | `auditeur-qualite` |

Ne choisissez pas un agent uniquement parce que son modèle vous semble « meilleur ». Le rôle définit la mission, les permissions et le contexte de travail. Les fiches détaillées sont sous `../02_AGENTS/`.
