# Construire et lire un plan

## Un bon plan contient

- tâches nommées ;
- propriétaire de chaque tâche ;
- entrées nécessaires ;
- dépendances ;
- sortie attendue ;
- contrôle de réussite ;
- ordre d'exécution.

## À vérifier avant exécution

1. le plan couvre tous les livrables ;
2. aucune tâche ne dépend d'une information absente ;
3. l'agent assigné a le bon rôle ;
4. les validations sont indépendantes lorsque nécessaire ;
5. les tâches peuvent être rejouées sans écraser l'historique.

Un plan n'est pas une promesse immuable : une clarification ou un échec peut légitimement le faire évoluer, mais le changement doit rester traçable.
