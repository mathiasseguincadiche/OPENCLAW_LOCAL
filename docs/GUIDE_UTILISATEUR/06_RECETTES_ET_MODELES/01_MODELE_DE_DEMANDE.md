# Modèle de demande générale

```text
OBJECTIF
Je veux obtenir : <résultat final>.

CONTEXTE
<état actuel, environnement, historique utile>

ENTRÉES
<fichiers, dépôt, logs, documents>

CONTRAINTES
- <ce qui est obligatoire>
- <ce qui est interdit>

LIVRABLES
- <sortie concrète 1>
- <sortie concrète 2>

CRITÈRES DE RÉUSSITE
- <preuve vérifiable 1>
- <preuve vérifiable 2>

MÉTHODE
Analyse avant d'agir. Signale les ambiguïtés bloquantes. Construis un plan. Exécute uniquement ce qui est nécessaire. Vérifie chaque changement et fournis les preuves et limites restantes.
```

Utilisez ce modèle comme base, puis adaptez-le au rôle choisi.
