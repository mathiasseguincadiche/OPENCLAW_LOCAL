# Recettes et modèles

Ces fiches servent à démarrer vite sans oublier les éléments qui rendent une mission vérifiable.

## Utilisation

1. choisir le modèle le plus proche du besoin ;
2. remplacer les zones entre `<...>` ;
3. supprimer les rubriques inutiles ;
4. ajouter les contraintes spécifiques ;
5. envoyer au bon agent ou utiliser le texte comme base de Project Intake.

Les modèles ne remplacent pas le jugement : un contexte incomplet doit rester explicitement incomplet.
