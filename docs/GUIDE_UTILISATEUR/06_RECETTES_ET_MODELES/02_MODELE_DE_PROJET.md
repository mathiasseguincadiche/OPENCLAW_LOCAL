# Modèle de cadrage projet

```text
TITRE
<nom>

BUT
<ce qui doit être vrai à la fin>

PÉRIMÈTRE
Inclus : <...>
Exclu : <...>

SOURCES
- <consigne>
- <dépôt/fichiers>

LIVRABLES
- <livrable + format>

CONTRAINTES
- <technologies, sécurité, temps, compatibilité>

VALIDATION
- <tests/commandes/critères>

DÉCISIONS HUMAINES PRÉVISIBLES
- <publication, suppression, choix d'architecture, etc.>
```

Ce texte peut devenir une consigne Markdown dans l'intake d'un nouveau projet.
