# Glossaire utilisateur

- **Agent** : rôle spécialisé avec mission, règles, outils et workspace.
- **Modèle** : LLM réellement chargé par le backend local.
- **Gateway** : service OpenClaw utilisé pour exécuter les agents.
- **Intake** : entrées initiales protégées servant de référence.
- **Projet central** : source de vérité persistante du projet.
- **Workspace** : copie de travail reconstruisible d'un agent.
- **Task** : unité de travail assignée à un rôle.
- **Artifact Exchange** : publication versionnée des sorties d'une tâche vers ses dépendants.
- **Evidence** : preuve mesurable qu'une action ou validation a eu lieu.
- **Gate** : condition obligatoire avant la transition suivante.
- **PASS / FAIL** : réussite ou échec d'un contrôle.
- **STOP** : arrêt volontaire du workflow ; pas forcément une panne.
- **Review** : contrôle indépendant après validation technique.
- **Package** : assemblage final des livrables et preuves.
- **Local-first** : le parcours local est nominal ; aucune bascule cloud silencieuse.
