# Comment travailler avec l'IA

Une bonne collaboration ne consiste pas à écrire « fais-moi ça » puis accepter la première sortie.

## Méthode courte

1. décrire le résultat voulu ;
2. donner le contexte et les sources ;
3. préciser les contraintes ;
4. définir les livrables ;
5. définir comment vérifier le résultat ;
6. laisser l'agent analyser avant de modifier ;
7. contrôler le plan ;
8. exécuter ;
9. valider avec preuves ;
10. corriger seulement ce qui échoue.

## Formulation recommandée

```text
Objectif :
Contexte :
Entrées :
Contraintes :
Livrable attendu :
Critères de réussite :
Avant d'agir : analyse, signale les ambiguïtés, propose le plan.
Après l'action : vérifie et fournis les preuves.
```

Pour un travail multi-fichiers ou multi-rôles, préférez un projet orchestré à une conversation isolée.
