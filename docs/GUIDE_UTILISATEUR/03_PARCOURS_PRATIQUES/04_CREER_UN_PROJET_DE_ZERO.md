# Créer un projet de zéro

## Préparer

Une consigne minimale décrivant objectif, contraintes et livrables. Des sources peuvent être absentes au départ si le projet consiste justement à les produire.

## Étapes

1. créer l'intake ;
2. vérifier `status` ;
3. lancer l'analyse ;
4. répondre aux clarifications ;
5. vérifier le plan et les assignations ;
6. lancer `run --execute` ;
7. suivre les gates ;
8. vérifier validation et review ;
9. inspecter `deliverables/` ;
10. approuver `complete`.

Consulter `../05_GERER_UN_PROJET/01_CREER_UN_PROJET.md` pour les commandes détaillées.
