# Faire un audit sécurité

## Agent principal

`ingenieur-securite` ; résultat vérifié par `auditeur-qualite` si livrable.

## Préparer

Périmètre, actifs, architecture, configuration, dépendances, politiques et changement à auditer.

## Demander

- modèle de menace adapté ;
- constats avec preuves ;
- gravité et exploitabilité ;
- correction proposée ;
- contrôle après correction ;
- risque résiduel.

## Attention

Un audit ne doit pas exécuter automatiquement une action destructive pour « prouver » un risque. Les gates humains restent prioritaires.
