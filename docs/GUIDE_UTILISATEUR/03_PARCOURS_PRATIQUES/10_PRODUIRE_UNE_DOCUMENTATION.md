# Produire une documentation

## Agent principal

`redacteur-technique`.

## Préparer

Sources de vérité, public cible, résultat attendu, commandes réellement validées et profondeur souhaitée.

## Structure recommandée

- objectif ;
- prérequis ;
- concepts nécessaires ;
- procédure ;
- résultat attendu ;
- contrôle ;
- erreurs fréquentes ;
- rollback/reprise ;
- références approfondies.

## Contrôle

Faire relire par l'Auditeur qualité lorsque le document devient un livrable. Une documentation ne doit jamais inventer une commande ou présenter un test non exécuté comme `PASS`.
