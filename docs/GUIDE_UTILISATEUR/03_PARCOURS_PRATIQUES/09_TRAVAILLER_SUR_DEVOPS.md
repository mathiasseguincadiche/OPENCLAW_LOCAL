# Travailler sur DevOps

## Agent principal

`ingenieur-devops`.

## Langages et surfaces typiques

PowerShell, Bash, YAML, Dockerfile, HCL/Terraform, Helm, manifests Kubernetes, Ansible, CI GitHub/GitLab et scripts d'automatisation.

## Méthode

1. établir l'état actuel ;
2. fournir fichiers et erreur ;
3. définir l'état final ;
4. demander un plan minimal ;
5. modifier par petites unités ;
6. analyser/linter/tester ;
7. vérifier le runtime ;
8. fournir rollback et preuves.

## Règle

Ne demandez pas seulement « écris le YAML ». Demandez ce que le changement doit garantir et comment il sera testé.
