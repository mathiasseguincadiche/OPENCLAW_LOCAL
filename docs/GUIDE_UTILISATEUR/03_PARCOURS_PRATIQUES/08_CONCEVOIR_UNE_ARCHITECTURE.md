# Concevoir une architecture

## Agent principal

`architecte-solutions` ; revue par sécurité et qualité selon le projet.

## Préparer

Besoins, contraintes, technologies imposées, charge, disponibilité, sécurité, exploitation, coût et évolutivité.

## Demander

1. hypothèses ;
2. au moins deux options lorsque le choix n'est pas évident ;
3. compromis ;
4. architecture retenue ;
5. flux/interfaces ;
6. risques ;
7. critères de validation ;
8. ADR si la décision est structurante.

L'architecture devient une entrée pour les tâches d'implémentation ; elle ne remplace pas les tests de ces tâches.
