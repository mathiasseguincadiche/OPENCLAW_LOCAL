# Modifier un projet existant

## Méthode

1. identifier précisément ce qui change ;
2. distinguer nouvelle exigence, nouvelle source et correction ;
3. consulter l'état du projet ;
4. mettre à jour les entrées par le mécanisme prévu plutôt que modifier les bundles d'échange ;
5. réanalyser/replanifier si l'impact le justifie ;
6. identifier les tâches et dépendants affectés ;
7. exécuter une nouvelle tentative ;
8. revalider et revoir ;
9. vérifier le nouveau package.

## Principe

Une modification ne signifie pas « réécrire tout le projet ». L'Artifact Exchange propage un résultat `PASS` vers les consommateurs affectés et conserve les anciennes tentatives.
