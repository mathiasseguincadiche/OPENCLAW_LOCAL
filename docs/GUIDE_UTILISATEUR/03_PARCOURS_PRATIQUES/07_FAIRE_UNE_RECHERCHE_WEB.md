# Faire une recherche Web

## Agent

`expert-recherche`.

## Préparer

Question, date/période, sources officielles prioritaires, éléments à comparer et niveau de confiance attendu.

## Parcours

```text
question → recherche Web → sources → vérification → synthèse locale
```

## Exiger

- dates des sources ;
- distinction source officielle / secondaire ;
- points de convergence et divergence ;
- citation des faits importants ;
- signalement de l'incertitude.

Une recherche Web ne signifie pas escalade du modèle vers le cloud. Le raisonnement reste local dans le parcours nominal.
