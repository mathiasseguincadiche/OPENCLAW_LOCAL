# ANALYZE

## But

Comprendre le besoin à partir de l'intake et des sources.

## Responsable principal

`chef-operations`, avec revue de recherche lorsque nécessaire.

## Sortie attendue

`context/project_analysis.json` doit décrire objectifs, contraintes, livrables, hypothèses, dépendances, risques et zones ambiguës.

## Ce qu'il faut contrôler

L'analyse ne doit pas inventer une information absente. Une ambiguïté réellement bloquante doit devenir une clarification, pas une hypothèse silencieuse.

## Suite

Aucune ambiguïté bloquante → planification. Ambiguïté bloquante → `CLARIFICATION_REQUIRED`.
