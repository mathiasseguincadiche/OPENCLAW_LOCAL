# PACKAGE / PACKAGING

## Responsable principal

`ingenieur-release-forges`.

## But

Assembler les livrables validés dans une forme finale identifiable.

## Sorties typiques

- `deliverables/package_manifest.json` ;
- archive ou ensemble final sous `deliverables/` ;
- hashes et preuves associées.

## Contrôler

Le package doit contenir les bonnes versions, pas un fichier de travail intermédiaire. Les éléments non validés ne doivent pas entrer dans le package final.
