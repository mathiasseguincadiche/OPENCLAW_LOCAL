# INTAKE_READY

## Signification

Le projet possède une entrée canonique inventoriée : consignes, sources et livrables attendus sont suffisamment structurés pour commencer l'analyse.

## Vérifier

- les bons fichiers ont été fournis ;
- les sources sont lisibles ou les limites sont signalées ;
- l'intake n'a pas été modifié après sa création ;
- les hashes/provenances existent ;
- aucun secret évident ou lien de fichiers dangereux n'a été accepté.

## Action suivante

Lancer l'analyse. Ne commencez pas à implémenter avant que le système ait transformé les entrées en compréhension structurée.
