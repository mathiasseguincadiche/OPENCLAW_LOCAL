# ASSIGN

## But

Associer chaque tâche à un rôle responsable.

## Sortie

`context/task_assignments.json`.

## Vérifier

- DevOps pour implémentation/exploitation ;
- Architecte pour conception ;
- Sécurité pour audit sécurité ;
- Rédacteur pour documentation ;
- Release/Forge pour packaging/publication ;
- Auditeur pour contrôles indépendants.

Le même rôle ne doit pas être choisi uniquement pour « tout faire plus vite ». La séparation des responsabilités est une partie du contrôle qualité du système.
