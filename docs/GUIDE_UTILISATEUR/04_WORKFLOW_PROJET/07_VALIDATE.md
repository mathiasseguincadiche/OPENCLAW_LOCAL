# VALIDATE

## Responsable principal

`auditeur-qualite`, avec revue sécurité pour les critères concernés.

## But

Vérifier objectivement les résultats des tâches.

## Sortie

`evidence/validation_report.json`.

## PASS

Les critères sont démontrés par des preuves suffisantes.

## FAIL

Les tâches concernées sont rouvertes, ainsi que les dépendants réellement affectés. Le projet revient vers `IN_PROGRESS`.

## À retenir

Une validation ne corrige pas silencieusement le livrable. Elle dit ce qui passe, ce qui échoue et pourquoi.
