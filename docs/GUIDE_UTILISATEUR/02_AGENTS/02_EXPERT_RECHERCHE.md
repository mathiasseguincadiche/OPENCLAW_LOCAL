# Expert recherche

## Quand l'utiliser

Documentation officielle, faits récents, comparaison de versions, recherche Web, vérification de sources.

## À lui fournir

Question précise, période pertinente, domaines/sources préférés éventuels, critères de fraîcheur et résultat attendu.

## Ce qu'il doit produire

Sources identifiables, faits séparés des hypothèses, divergences éventuelles et synthèse exploitable par les autres rôles.

## Ne pas l'utiliser pour

Décider seul d'une architecture ou transformer une information récente en permission de basculer le LLM dans le cloud.

## Exemple

```text
Vérifie dans la documentation officielle les changements de schéma entre les versions X et Y. Cite les éléments qui affectent notre configuration et distingue les faits des recommandations.
```
