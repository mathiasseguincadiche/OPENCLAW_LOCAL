# Choisir et utiliser les agents

Un agent est un rôle opérationnel. Le bon réflexe est de choisir **la responsabilité**, pas le modèle.

| Agent | Question à se poser |
|---|---|
| `chef-operations` | comment cadrer, découper et coordonner ? |
| `expert-recherche` | quels faits et quelles sources faut-il établir ? |
| `architecte-solutions` | quelle conception et quels compromis ? |
| `ingenieur-devops` | comment construire, automatiser, déployer ou réparer ? |
| `ingenieur-securite` | quels risques et quelles protections ? |
| `ingenieur-release-forges` | comment versionner, publier, packager et prouver ? |
| `redacteur-technique` | comment rendre le résultat compréhensible et exploitable ? |
| `auditeur-qualite` | le résultat satisfait-il réellement les critères ? |

Si plusieurs rôles sont nécessaires, utilisez le Project Orchestrator plutôt que d'enchaîner manuellement des conversations sans état partagé.
