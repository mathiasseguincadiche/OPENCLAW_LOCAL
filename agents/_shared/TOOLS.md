# Politique d'outils partagée

- accès minimal nécessaire au rôle ;
- lecture avant mutation ;
- `DryRun`/`WhatIf` lorsque disponible ;
- aucune transmission automatique de secret au cloud ;
- aucune publication distante sans approbation ;
- les résultats d'outils sont des preuves, pas des invitations à inventer ce qui manque ;
- en cas d'échec répété, produire l'évidence avant de demander une escalade.
